# landing-brand-compliance Specification

## ADDED Requirements

### Requirement: Digital Studio Brand Positioning
The system SHALL state Aetthel's brand positioning strictly as a digital studio for landing pages, web applications, and process automations in site configuration and SEO metadata.

#### Scenario: Site metadata inspection
- **WHEN** site metadata is rendered or queried
- **THEN** description and keywords contain digital studio services and exclude architecture or brand space references

### Requirement: Illustrative Mockup Visual Labeling
The system SHALL label gallery work samples visually as illustrative mockups ("Maqueta ilustrativa") per brand evidence rules.

#### Scenario: Gallery item rendering
- **WHEN** a user views work samples in the home gallery
- **THEN** each sample slide presents a clear, legible badge or label marking it as an illustrative mockup
